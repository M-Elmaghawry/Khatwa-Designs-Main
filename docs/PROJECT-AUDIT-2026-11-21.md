## نتائج التحقق

| الفحص | النتيجة |
|---|---|
| `npm run build` | نجح؛ توليد 21 مسارًا مع مداخل العربية والإنجليزية |
| `npm test` | 26 اختبارًا ناجحًا، دون إخفاقات أو اختبارات متجاهلة |

| `npm audit` للتطبيق والجذر | صفر ثغرات معروفة وقت الفحص، بما فيها حزم التطوير |
| فحص المتصفح | 64 حالة: 16 صفحة × لغتين × عرضي 390 و1440 بكسل |
| تحميل الصور والأصول المحلية | لا صور مكسورة ولا استجابات محلية فاشلة في الحالات المفحوصة |
| JavaScript واتجاه النص | لا استثناءات في الصفحات المفحوصة؛ RTL/LTR صحيحان |
| العرض | عنوان رئيسي واحد لكل صفحة؛ لا تجاوز أفقي في المقاسين المفحوصين |
| القوائم والفلاتر | قائمة الموبايل وقائمة الخدمات تعملان؛ فلتر المواقع يعرض 5 مشاريع |

| ملفات القفل | `npm ls --depth=0 --prefix khatwa` ناجح |
| تنسيق التغييرات | `git diff --check` ناجح |

## الملاحظة المتبقية في البيئة

Node المحلي هو `24.14.0`؛ التطبيق وبعض حزم الاختبار تشترط `24.15.0` أو أحدث ضمن فرع Node 24، أو إصدارًا آخر مطابقًا لحقل `engines`. نجح البناء والاختبار على البيئة الحالية، لكن يلزم تحديث Node لنسخة مدعومة قبل التثبيت التالي. لم تُغيّر إعدادات Node العامة أو إصدارات حزم التطبيق تلقائيًا.

## إعادة تشغيل المراجعة

من جذر المشروع:

```powershell
npm.cmd run build
npm.cmd test
npm.cmd run audit:files
npm.cmd audit
npm.cmd audit --prefix khatwa
```

لفحص المتصفح شغّل `npm.cmd run preview`، ثم افتح جلسة `playwright-cli` على `http://127.0.0.1:4173/Khatwa-Designs-Main/` وشغّل `khatwa/scripts/browser-audit.cjs`. يعيد السكربت النتيجة ويحفظ اللقطات داخل `.local-backup/` المستثنى من Git. راجع `README.md` لتعليمات التشغيل وتعديل المحتوى.
