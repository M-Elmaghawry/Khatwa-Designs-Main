# ابدأ من هنا — تشغيل GitHub Copilot على موقع Khatwa Designs

هذا الدليل يشرح استخدام ملفات التعليمات والمحتوى الموجودة في هذا المستودع. إذا كنت تنقل الحزمة إلى نسخة أخرى من الموقع، ادمج الملفات مع الموجود ولا تستبدل أي تعليمات أو مستندات مهمة دون مراجعتها.

## الملفات التي ستستخدمها

- `.github/copilot-instructions.md` — تعليمات دائمة لمساعدة Copilot على احترام الهوية البصرية، ونطاق الخدمات، واللغتين، وتكامل EmailJS.
- `.github/prompts/01-audit-site.prompt.md` — مراجعة الكود وخطة التنفيذ دون تعديل الموقع.
- `.github/prompts/02-implement-content.prompt.md` — تنفيذ المحتوى على دفعات صغيرة.
- `.github/prompts/03-qa-review.prompt.md` — اختبار الموقع والتأكد من عدم كسر الروابط أو اللغات أو نموذج التواصل.
- `Khatwa_Designs_Content_Master_AR_EN_v1.md` — مرجع المحتوى العربي والإنجليزي.
- `COPILOT_TASKS_AR.md` — التعليمات نفسها بصيغة سهلة للنسخ واللصق، إذا لم تظهر ملفات Prompt في واجهة Copilot لديك.

## طريقة التركيب في VS Code

1. افتح مجلد المشروع الحقيقي في VS Code، أي المجلد الذي يحتوي على ملفات الموقع وملفات Git، وليس مجلدًا منفصلًا فارغًا.
2. تأكد من وجود نسخة احتياطية أو التزم بالتعديلات الحالية في Git قبل بدء العمل. نفّذ `git status` وتأكد أنك لا تخاطر بتعديلات لم تحفظها.
3. إذا كنت تنقل هذه الملفات إلى مستودع آخر، انسخ محتويات `.github` و`docs` إلى جذره وادمجها مع الموجود. راجع التعارضات يدويًا ولا تستبدل تعليمات أو مستندات مهمة. مرجع المحتوى دليل للتطبيق وليس بديلًا عن ملفات HTML أو JavaScript، والحزمة لا تغيّر الموقع المنشور بمفردها.
4. في Copilot Chat، ابدأ بوضع Ask/Plan أو ما يعادله، ثم شغّل `01-audit-site` إن كانت ملفات Prompt متاحة. لا تطلب منه تعديل الموقع في أول خطوة.
5. راجع تقرير التدقيق. بعدها شغّل `02-implement-content` أو انسخ نص المهمة المقابل من `COPILOT_TASKS_AR.md` إلى Copilot Chat. استخدم Agent/Edit عندما تريد تنفيذ تعديلات فعلية.
6. بعد كل دفعة، راجع الـdiff في Source Control، وافحص التغييرات قبل قبولها. لا تقبل كل الملفات تلقائيًا.
7. بعد انتهاء التنفيذ شغّل `03-qa-review`، ثم افتح الموقع محليًا واختبر اللغتين والنموذج يدويًا.
8. لا تنشر إلى GitHub Pages قبل مراجعة النسخة النهائية بنفسك.

## ترتيب العمل المقترح

- أولًا: تدقيق الملفات وخريطة اللغة والنموذج والروابط.
- ثانيًا: الهيدر والفوتر والرئيسية وقائمة الخدمات.
- ثالثًا: صفحات الخدمات الخمس.
- رابعًا: من نحن، الأعمال، والتوصيات.
- خامسًا: التواصل وSEO وإخفاء المقالات التجريبية.
- سادسًا: اختبار شامل عربي/إنجليزي وموبايل/ديسكتوب.

## ملاحظة مهمة عن ملفات Prompt

ملفات `.prompt.md` مفيدة في واجهات VS Code التي تدعم Prompt Files، لكن توفرها يعتمد على واجهة/وضع Copilot المستخدم. إذا لم تظهر أو لم يستجب الأمر `/01-audit-site`، افتح `COPILOT_TASKS_AR.md` وانسخ نص المهمة يدويًا إلى المحادثة. ملف `.github/copilot-instructions.md` هو ملف التعليمات الدائم للمستودع.

## طلب البداية الذي ترسله إلى Copilot

> اقرأ `.github/copilot-instructions.md` و`Khatwa_Designs_Content_Master_AR_EN_v1.md` بالكامل. افحص المستودع الحالي وGit status، وحدد ملفات كل صفحة، وآلية اللغة العربية/الإنجليزية، وطريقة إظهار/إخفاء المحتوى، ونموذج EmailJS، والروابط الداخلية والخارجية. لا تعدّل ملفات الموقع الآن. أعطني تقرير تدقيق وخطة تغيير ملفًا بملف، مع ذكر المخاطر والاختبارات المطلوبة. لا تفترض أن أسماء الملفات الواردة في مرجع المحتوى تطابق بنية المستودع قبل فحصها.
