# Installation notes

Copy the contents of this kit into the ROOT of the existing website repository.

- Merge `.github/copilot-instructions.md` and `.github/prompts/` with existing files; never blindly replace existing instructions.
- Copy `docs/Khatwa_Designs_Content_Master_AR_EN_v1.md` and `docs/COPILOT_TASKS_AR.md` into the repository's `docs/` directory. If `docs/` already contains important project documentation, keep it.
- The content master is a guidance document, not a replacement for source HTML/JS files.
- The kit does not include the website source code and does not change the live site by itself.
