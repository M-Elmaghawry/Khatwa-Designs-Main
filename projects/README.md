# Portfolio thumbnails

The public portfolio contains only the 23 projects supplied by the owner. Current behance-*.svg files are explicitly labelled waiting covers, not project screenshots. Titles without a supplied project name use a neutral service label and sequence number.

Prepare **1200 × 900 px (4:3)** thumbnails, ideally WebP, targeting 150–250 KB per image. Keep logos and essential text away from the edges. Use the Behance project ID as the filename (for example, behance-215345183.webp). Update the matching image extension in portfolio.html and index.html, then run content:sync and rebuild React.
