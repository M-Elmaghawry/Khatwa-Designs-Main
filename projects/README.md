# صور المشاريع

هذه الملفات أغلفة مؤقتة طلبها صاحب الموقع، وليست صورًا لأعمال منفذة. الألوان هي ألوان البراند، واللوجو الأصلي لم يتغير.

لإضافة صورة حقيقية: ضع ملف WebP أو JPG داخل هذا المجلد، ثم حدّث امتداد الصورة المقابلة في index.html وportfolio.html. يفضل مقاس 1200×900 (نسبة 4:3) ووزن أقل من 200KB مع قص يحافظ على تفاصيل التصميم. الصورة تعرض الاسم والتصنيف في البطاقة؛ تجنب كتابة معلومات المشروع داخل الصورة فقط. لا تستبدل SVG بمحتوى JPG دون تغيير الامتداد.
